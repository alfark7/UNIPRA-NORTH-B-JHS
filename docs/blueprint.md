# **App Name**: UPNG Academic Hub

## Core Features:

- Student Data Management: Create, read, update, and delete student records with fields for personal details, guardian information, and class assignments.
- Academic Record Entry & Computation: Enter raw scores for tests, group work, projects, and exams, with automatic computation of class scores, exam scores, total scores, and grades.
- Academic Calendar Management: Manage academic events, terms, and important dates for the school year. Set key calendar dates for the different terms.
- Attendance Tracking: Record and track daily student attendance, generate monthly summaries, and visualize attendance data.
- Termly Report Card Generation: Automatically generate student report cards including student information, attendance summaries, scores, grades, remarks, and aggregate calculations.
- AI-Powered Remark Generation Tool: Suggest relevant and context-aware teacher and head teacher remarks based on student performance and behavior.
- Performance Analysis Dashboard: Provide a tool for interactive charts to analyze student performance across classes, subjects, and gender, and to compare performance across terms. Output to PDF/image formats.
- Teacher Data Management: Maintain teacher records including personal information, roles, subjects taught, contact details, and employment history.
- Settings Management: Manage system settings such as school logo, email, database backups, user permissions, and theme preferences.

## Style Guidelines:

- Primary color: Blue (#007BFF) for trustworthiness and stability, reflecting the academic environment.
- Secondary color: White (#FFFFFF) for a clean and modern look.
- Accent color: Red (#DC3545) to highlight important actions and draw attention to key data.
- Font pairing: 'Space Grotesk' (sans-serif) for headings and 'Inter' (sans-serif) for body text, offering a modern and readable aesthetic.
- Use clean, professional icons to represent different modules and actions, ensuring clarity and ease of use.
- Employ a grid-based layout to maintain consistency and responsiveness across different screen sizes, with clear separation of sections for easy navigation.
- Implement subtle animations for transitions and interactions to enhance user experience and provide feedback, without being distracting.
